# D4: shrink_to_new_bed bed re-centering (3MF + loaded machine)

Upstream revision: OrcaSlicer v2.4.2 (`OrcaSlicer/src/`).
This is the last open item of the O3-BBL chain: after D4 lands, the
`embedded-script` case upgrades to the whole-file comparison that
completes the chain exit criterion
(`o3-bbl-profile-overlay-triage.md`, "Known native nondeterminism" section
aside).

## What upstream does

When a BambuStudio-family 3MF is loaded together with `--load-settings`
machine presets, the CLI re-centers the embedded model and wipe tower onto
the loaded machine's bed:

1. BBL-family detection — `Format/bbs_3mf.cpp:3945-3957`: the archive's
   `Application` metadata starting with `BambuStudio-` or `OrcaSlicer-` sets
   `is_bbl_3mf` (`OrcaSlicer.cpp:1622-1643` threads it out of
   `Model::read_from_file`).
2. Old-bed extraction — `OrcaSlicer.cpp:1773-1781`: from the EMBEDDED config
   (before the machine overlay), `old_printable_area = printable_area`,
   `old_exclude_area = bed_exclude_area`,
   `old_printable_width/depth = (int)(area[2] - area[0])`,
   `old_printable_height = printable_height`.
3. Current bed — `OrcaSlicer.cpp:3708,3729-3735`: `current_*` comes from the
   overlaid print config (the loaded machine's `printable_area`); unset old
   values default to the current ones.
4. Classification — `OrcaSlicer.cpp:3766-3796` (guarded by
   `is_bbl_3mf && old_* > 0`):
   - old larger than current (width, depth, or height) → `shrink_to_new_bed = 2`
   - old width or depth smaller than current → `= 1`
   - equal sizes but `bed_exclude_area` changed → `= 2`
   - otherwise `= 0`
5. Application — `translate_models` lambda `OrcaSlicer.cpp:3958-4053`,
   invoked at `:4070` after plate load:
   - `shrink == 1`: per plate,
     `offset = (new_origin + current_size/2) - (cur_origin + old_size/2)`;
     `translate_all_instance(offset)` for every instance
     (`:4008-4021`); the plate-0 offset is remembered as `wipe_offset`
     (`:4015-4017`).
   - `wipe_tower_x`/`wipe_tower_y` (when present in the overlaid config)
     gain `wipe_offset` per plate index (`:4038-4048`).
6. Ender-3 3MF (220×220) + Bambu Lab X1 Carbon (256×256): old < new →
   `shrink = 1`, offset `+18/+18`, instance positions shift by 18 on both
   axes and `wipe_tower_x/y` `15,220 → 33,238` — exactly the residual
   difference the `embedded-script` case shows after D5/D2/D6.

## Included behavior

- `Application`-tag BBL-family detection (parse the 3MF metadata Ares already
  reads; `bbs_3mf.cpp:3945-3957`).
- Old-bed extraction from the embedded raw (`printable_area`,
  `bed_exclude_area`, `printable_height`).
- Classification exactly as `:3766-3796` (including the height comparison and
  the exclude-area-equal branch), with `shrink = 0` meaning no-op.
- `shrink == 1` application: all plate instances translated by the center
  delta; `wipe_tower_x/y` shifted by the plate-0 delta — in
  `Project::from_3mf_with_profiles`, after the merged raw resolves the loaded
  machine's `printable_area` and before the typed settings build, mirroring
  upstream's overlay→translate→slice order.
- Whole-file comparison for the `embedded-script` case becomes the D4 RED
  (fails at the first shifted coordinate) and the D4 GREEN proof.

## Deferred (each its own slice, none exercised by the `embedded-script` case)

- `translate_old` (pre-1.5.9 3MF version path, `OrcaSlicer.cpp:1664-1666`,
  `:3800-3803`, `:3965-3973`).
- `shrink == 2` object-bbox re-centering with exclude-area math
  (`:4022-4051`) and `shared_center_x/y` multi-extruder shared beds
  (`:3716,3740-3762,4015-4027`).
- Multi-plate `translate_old` instance translation and
  `plate_list.reset_size` bookkeeping (Ares has no plate-list size state).

## Destination boundary

`crates/ares-core/src/project/domain/profile_input.rs`
(`Project::from_3mf_with_profiles`): the embedded raw already carries the
old bed (`printable_area`), the composed settings carry the loaded machine's
`printable_area`, and the model instances live on the loaded
`Project` — the same point where `Placement` translation already exists
(`domain/placement.rs`). `wipe_tower_x/y` are merged-raw keys and shift
before the typed build. STL entries keep the
existing no-bed-state path (`:3729-3735` defaults make old == current there
only for 3MF; the STL branch never carries an embedded bed).

## RED plan

Extend the existing `embedded-script` flow (Ender-3 3MF + BBL X1C catalog +
user process, the D5/D2 test inputs) to the whole-file comparison: RED fails
at the first shifted coordinate (the `+18` bed re-centering), GREEN passes
whole-file with only the `; generated by` banner normalized — completing the
chain exit criterion.
