## 3. Runtime ownership decision

**Keep the comparisons in their existing crate/public-API seams**, not move them into ares-cli. No vgcode/wasm test may import/depend on ares-cli or OrcaRunner. No new crate/workspace member, production I/O, build.rs provisioning, or general oracle framework.

- Native execution/projection/provenance owner: existing `tools/chain-probe/marker-time-fixtures.mjs` and `marker-time-pair.mjs`, with focused shared helper only for their common run/receipt contract if needed. `fixtures` gains REQUIRED explicit artifact-directory argument (no repository-output default); `pair` already takes input/directory. Both may be imported by a thin browser test adapter or invoked by Rust test support. Node is a test-tool dependency, not a crate/production dependency; unavailable Node is visible SKIPPED in optional mode and FAIL in require mode, exactly like missing Native. No frozen fallback.
- Rust invocation/availability adapter: `tests/support/marker_time.rs`, included by the vgcode/wasm integration tests, using existing `tests/support/native_environment.rs` for unset/require policy. It starts the generator with explicit source input and fresh artifact directory, waits for success, then returns those paths. It does not own sums, selection, conversion, or a cached expected fixture. New modules remain <400LOC.
- Browser adapter: marker-specific Playwright setup calling the SAME generator, reading its fresh native.json. `test.skip`/visible annotation when optional Native unset; `ARES_REQUIRE_ORCA=1` is always FAIL even in CI. Do not modify global `oracleEnv.ts` policy for unrelated tests.
- Raw fixture run feeds runtime vertices.tsv/synthetic.tsv/moves.csv/native.json to the unchanged parsers/assertions. Tagged run receives the SAME freshly generated G-code whose public WASM output is tested, runs BOTH raw+stable producers and the existing bounds verifier, then feeds runtime stable.tsv to the unchanged identity/bit comparisons.

Protocol: optional unset/unavailable Native or unavailable Node → visible `SKIPPED: ... Native comparison not executed`; require mode → FAIL. Configured empty/missing/non-executable Native path, bad output/schema, Native nonzero/timeout → FAIL in both modes; these are not missing-tool skips. For tagged tests BOTH binaries are required to run the full assertion body; no stable-only or raw-only success. Provenance oracle names refer only to fresh files; setting a path to frozen JSON is not provisioning a producer.

Each consumer invocation uses a unique external artifact directory (configured parity artifact root or an isolated temp directory) and retains input, JSON/CSV/TSV projections, executable/extraction/input/output hashes, exact argv/environment, stdout/stderr/status. No shared repository/target output race, old-cache admission or auto-copy from frozen files. Bound Native raw/stable generation by one shared300s deadline, with owned-descendant cleanup; tool extraction and crate prebuild occur beforehand.
