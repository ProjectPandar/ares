# Plater filament assignment

## Source boundary

OrcaSlicer v2.5.0 (`40ecc66f78ed72dc368e0c1ebe40d77f00cc8a19`). `src/libslic3r/Model.cpp:2690–2700` (`ModelVolume::extruder_id`) resolves the explicit positive volume slot, then its object's slot, then slot 1. `PrintObject.cpp:4289,4395` owns object and region configuration; the Prepare edit changes that model configuration, not printer nozzle mapping, paint or G-code. The project reader already loads the same `extruder` metadata from `Format/bbs_3mf.cpp` into `RegionOptionOverrides::extruder` on `ProjectObject` and `ProjectVolume`.

## Prepare contract

- The list uses `src/slic3r/GUI/GUI_ObjectList.cpp:1664–1707`; the 3D path uses `Plater.cpp:14210–14266`. Normal object, part and mixed-selection menus route to `GUI_Factories.cpp:2122–2173,2190–2272`, which calls `append_menu_item_change_filament` (`:2553–2638`). The similarly named `append_menu_item_change_extruder` (`:1124`) serves Assemble, not these Prepare menus. The list's dedicated instance-only menu (`:2108,2177`) does not offer the command; a full instance in the canvas uses the object menu, and an instance in a mixed eligible selection edits its parent object.
- Show **Change Filament** for one selected item and **Set Filament for selected items** for several, when there are at least two project filament slots. Each slot has its swatch and preset label (fall back to Filament N if the preset is unavailable); unlike the Assemble menu, the current slot is not disabled. Offer an uncoloured **Default** only when a selected volume is a parameter modifier (`GUI_Factories.cpp:2563–2632`). A lone negative, blocker or enforcer does not receive the command.
- Apply `ObjectList::set_extruder_for_selected_items` (`GUI_ObjectList.cpp:6895–6982`) in selection order, not grouped or reordered by type. For each instance use its object; for each volume accept only a model part or parameter modifier. The selected slot is one-based. Choice zero writes `1` on an object, writes the parent's slot **at that point in the loop** on a normal part, and writes `0` on a modifier (`:6933–6941`). An object edit removes explicit `extruder` from its normal model parts, not from parameter modifiers (`:6964–6972`); if an explicitly selected part is encountered later, its edit is applied after the reset. Do not reproduce the upstream volume index bound typo or give instances independent configuration.
- Refresh the object-list filament indicator and colour of each colourable volume using the current slot palette, not the first project colour (`GUI_ObjectList.cpp:1094`, `3DScene.cpp:763,1020`). Keep selected-object feedback and non-model materials distinct.

## Destination boundary

- `ares-core/src/plater` owns the edit and its snapshot. Mutate the typed project region overrides in order and replay the edited assignments in `project/domain/plater_edits.rs` with `PlaterEdits` before selecting the slice plate, for both a byte-source 3MF and the in-memory source of STL sessions. Store metadata on the project model, not in a UI-only map; keep explicit zero distinct from no assignment. Use stable object/volume identities for replay and expose the model values for eventual `Metadata/model_settings.config` serialization. Existing instance/layout-only edit transport is extended, not used as an independent assignment model.
- `ares-wasm` exposes the mutation and raw/effective scene slots. The worker protocol and app send selected targets to the session, use one undo snapshot per action, and refresh the list and viewport from the returned slots. The web owns menu availability, selection and colouring; the existing project loader, region configuration and tool-ordering pipeline remains the only slicer.
- Save Project serialization is separate; its writer reads the typed model metadata, not the displayed effective colour. The combined assign → save → reopen → slice test belongs with integration. Inline cell editing is also separate: `GUI_ObjectList.cpp:1151–1195,1719–1755` takes a different path and clears **all** volume overrides on object edits, unlike this context-menu action. Slot count/colour editors, nozzle mapping, print order, Assemble and paint are out of scope.

## Public verification

Use a synthetic two-filament scene with two identifiable objects. Assign the second object through Prepare, slice and download, and check that each object's extrusion uses the designated tool and that the Filament legend shows both. Exercise model-part and modifier choices, ordered mixed targets, recolouring and undo/redo at the Prepare or plater session boundary. Construct the equivalent assigned 3MF independently; compare its bytes of sliced G-code with Native through the project parity family and compare the browser download using the same scene, settings and generation inputs. Keep generated outputs out of the source tree.
