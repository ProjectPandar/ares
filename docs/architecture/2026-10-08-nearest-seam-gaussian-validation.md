## Implementation and arithmetic

RED is `f833e0416f538bb1e8655304e430c1f97ad3f353`; GREEN is
`c70d7a22df779c67cb80e6697e712bcaf68a19ff`.
The implementation replaces `exp(e)` normalization and reciprocal
multiplication with `(exp(exponent) - 1) / (exp(1) - 1)`.
Exponent evaluation, subtraction and division retain upstream f32 operation
order. Each exponential widens the f32 input, evaluates f64 exp, then narrows
once before further arithmetic, matching the existing angle-penalty strategy.
Both upstream call sites fix mean to0 and mean_value to1; Rust's specialized
helper therefore loses no caller parameter. The exact no-op multiplication
by1 was removed in GREEN's coordinator-requested amend. No tie rule,
candidate ordering, angle penalty, timing model or wipe logic changed.
