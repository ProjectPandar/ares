## Rust destination and included behavior

`crates/ares-core/src/project_slice/gcode_emit/machine.rs::
append_second_layer_transition` currently reduces every configured ordinary
bed-temperature column for HighestTemp. Replace only that settings-only
maximum with the existing `EmitState.initial_filaments.first_layer_tools()`
context. Read each logical filament with front-on-miss semantics and fold
from zero. Preserve the bed-type selection, writer cache, command formatting,
nozzle transitions, and first-to-second-layer lifecycle.

The earlier initial-layer reader already carries this context in
`machine/first_filaments.rs` and `machine/temperature.rs`; it is reused,
not reimplemented. The existing scaffold remains only a compatibility shell
around this source-owned reader until adjacent behavior is ported.

## Deferred behavior

FirstFilament's process-layer filament choice is outside this HighestTemp
slice. Also deferred: sequential first-layer usage union, mixed-filament
expansion, ToolOrdering producer changes, initial-layer reader changes,
configuration serializers, preset selection/refresh, warning transport,
and thermal G-code scanning. This slice must not change parser syntax,
config vectors, defaults, or physical-nozzle mapping.

Compatibility-expression groups are not generated by this reader. Native's
system-filament refresh (`src/OrcaSlicer.cpp:2778–2821,3509–3510,3715–3729`)
creates them when resolved scalar conditions are merged. Ares already ports
that behavior through its explicit project preset catalogue. Do not insert
hardcoded empty groups or add implicit vendor discovery to compensate for
an absent catalogue.

Core remains byte-oriented and filesystem/environment/UI-free on WASM,
Windows, macOS, and Linux. No new dependency or fallback is needed.

## Failure inventory and E2E contract

Use only authored synthetic 3MF inputs, never Native-export-derived input.
Derive witnesses from the existing synthetic
`tests/parity/m140-initial-bed/unused-hotter-filament.3mf`, retaining model
and tool assignment and changing only authored temperature values.

- An unused hotter filament must not cause an M140 at layer two when the
  used filament's initial and ordinary temperatures are equal.
- A cooler ordinary target for the used filament must emit that target,
  not the unused hotter filament's value; this rejects deleting all M140s.
- The complete initial-temperature vector and start placeholder must stay
  unchanged. Native must actually extrude model paths with filament 1 alone.
- Changed temperatures must retain writer-cache updates, and an unchanged
  target must remain suppressed. Existing initial-bed controls remain intact.

Run each input against official and seeded Native modes with reference and
fresh replay using the existing generator-only comparison. Exercise the
public API and actual CLI with identical bytes; require success and raw
API/CLI equality. Preserve complete outputs and strict whole-output first
differences. The existing labelled start-section and all-bed-command oracle
is the comparison boundary: it compares Native's complete M140/M190 sequence,
not a hand-produced command list. A labelled PASS does not imply whole-file
parity when an unrelated config/footer difference remains. Never add masks,
tolerances, or comparator exceptions.
