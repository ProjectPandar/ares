# Type2 tower template serialization

OrcaSlicer v2.5.0 (`40ecc66f78ed72dc368e0c1ebe40d77f00cc8a19`) owns this boundary. `GCode.cpp:1941–1953` supplies three scalar `ConfigOptionString` values to `WipeTowerIntegration::append_tcr2`: `change_filament_gcode`, `restore_layer_z_before_toolchange`, and `deretraction_from_wipe_tower_generator`. The tower uses legacy square-bracket tokens for all three (`GCode/WipeTower2.cpp:1742–1743,1846`), so legacy expansion calls `serialize()` (`PlaceholderParser.cpp:1064–1067`). `ConfigOptionString::serialize` (`Config.hpp:1172–1175`) escapes CR, LF, backslashes, and double quotes (`Config.cpp:76–97`).

The writer scans the expanded but still escaped template for acceleration and jerk commands (`GCode.cpp:854–875,5387–5395`); `append_tcr2` unescapes only afterward (`:1950–1953`, `Config.cpp:150–170`). Embedded line breaks in a substitution are not physical line breaks during the scan. On the U1 witness, the tower entry travel has already set the writer cache to 10000. Ares used to expose the substitution's `SET_VELOCITY_LIMIT` on a new physical line during the scan, invalidating that cache and producing a redundant command on the return to model travel. Native keeps the cache, while still emitting the entry travel's command in the decoded output (`GCode.cpp:10562`, `GCodeWriter.cpp:535–580`).
