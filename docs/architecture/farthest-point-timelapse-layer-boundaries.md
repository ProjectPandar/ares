# Farthest-point timelapse layer boundaries

OrcaSlicer 2.5.0 (`40ecc66f78ed72dc368e0c1ebe40d77f00cc8a19`), `GCode::process_layer` in `src/libslic3r/GCode.cpp`, owns the placement of generated timelapse G-code in a physical layer. This slice ports its two farthest-point boundary decisions. It does not change which paths determine the target (B60-03) or which extrusion endpoint satisfies it.

- **Start (`:6717–6722`, `:7395–7420`):** when the existing traditional-placement gate is false and the printer is BBL, skip the existing tracked layer-start render only if farthest-point is enabled **and this layer's target belongs to the photo head**. A one-nozzle machine with no candidate does not satisfy that condition. In Rust, `gcode_emit/layers/boundary.rs` reads the result already computed by `layers/farthest.rs`, rather than deriving a second predicate from nozzle count.
- **End (`:8192–8227`):** after all extrusion visits, merge the inline latch into the insertion flag. For an enabled photo-head target with no prior inline or traditional insert, retract/lift if `retract_when_changing_layer` is set, flush the pending object-change labels, then render the tracked timelapse with position picking enabled (not the inline template mode). Mark the layer inserted so the traditional tail cannot render again. In Rust this belongs to the physical layer tail in `gcode_emit/layers`, before the layer stream is handed to cooling, using the existing retract, label, and tracked-render ports. The existing per-entry traditional tail is a compatibility shell for the same upstream tail; it must not run a second insert or eager retract for this case.

Non-BBL layer-change rendering, the traditional gate and interludes, target eligibility/traversal, the inline distance check, and safe-position picking are outside this slice. Neither the absence of an object layer nor the presence of object labels is the photo-head predicate. The upstream untracked layer-change and BBL layer-start renders are not writes to the local inline/traditional insertion latch.

Public parity witness: `tests/parity/negative-volume-seam-occlusion/negative-target.3mf`, adding only object-level `wall_loops=0`. The pinned X1 Carbon printer preset supplies the farthest-point toggle. Compare the first-layer lift and snapshot before deposition, and the Z=0.8 snapshot after deposition, retract/lift, and pending stop label, against Native. The regression compares the observable snapshot sequence, not unrelated feedrate or ETA differences. The unchanged negative-volume control and existing farthest-point/ordinary timelapse cases protect the successful inline and inactive paths.
