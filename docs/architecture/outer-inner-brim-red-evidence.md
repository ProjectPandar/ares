# OuterAndInner brim: admitted Native RED

This is the separate fixtures/tests RED; no production code is changed.

## Reproducible inputs and public seams

Ten input-only 3MF archives are generated by
`tests/parity/outer-inner-brim/generate.py`. Repeating generation produces
identical bytes. Every directed mesh edge has one reverse, signed volume is
positive, and no archive member is G-code. Provenance records requested
options, mesh counts, contours, holes and SHA256. Two islands are in one mesh,
volume/object/instance/tool. Support, EFC, skirt, tower and infill are disabled.

The tests call original Native Slice, the validated byte API and real CLI.
Native effective brim type/width/gap/EFC equals requested settings. All ten
inputs in both modes have Native return0, API success and CLI exit0. Admission
errors are not counted as RED. Native first-layer positive Brim XY/E witnesses
use input polygon membership; complete generator-only byte comparisons remain
the unchanged acceptance check for API and CLI.
