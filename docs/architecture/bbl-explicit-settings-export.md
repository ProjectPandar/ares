# Exporting settings from BBL 3MFs with explicit presets

OrcaSlicer v2.5.0 (`40ecc66f78ed72dc368e0c1ebe40d77f00cc8a19`) writes the composed `DynamicPrintConfig` through `libslic3r/Config.cpp:1546–1589` (`ConfigBase::save_to_json`); `CLI::run` passes it to the writer at `OrcaSlicer.cpp:6326–6334`. Writing settings does not require slicing a plate.

- `libslic3r/Preset.cpp:1090` (`Preset::load_external_config`) supplies the defaults of retained printer and process presets only. The calls at `OrcaSlicer.cpp:3164–3200` are skipped for explicitly loaded kinds. A named explicit printer also suppresses saved filament preset lookup (`:2775–2817`). Apply the selected printer and process keys (`:3099–3162`, `:3256`, `:3406`) and each explicitly loaded filament to its slot (`:3563–3622`, `:3738–3792`), preserving options absent from those presets. Complete the config with `FullPrintConfig` and its filament layout (`:4250–4259`, `libslic3r/PrintConfig.cpp:11402–11427`), not with defaults for replaced presets.
- `OrcaSlicer.cpp:2418–2455` records loaded filament slots and names. The BBL one-name mapping rule (`:2528–2535`) disables `enable_prime_tower` and adds it to the process entry of `different_settings_to_system` (`:4323–4342`). This change is visible in the serialized config; it does not collapse the two slots.

The single-3MF early return in `ares-cli/src/direct_stl.rs` currently treats all settings exports as saved-config exports, even when explicit presets were supplied. Replace that shortcut for the explicit BBL route with a call from the CLI settings adapter into the existing `ares-core` composition at `profiles/load_settings.rs::compose_project_load_settings` and `project/domain/profile_input/three_mf.rs`. Start from the imported configuration before retained defaults are filled for replaced kinds. Reuse the existing mapped-tower rule and `project/settings_export.rs::export_loaded_settings`, the Rust `ConfigBase::save_to_json` boundary. Keep the saved-only settings adapter for the no-load case; do not filter serialized keys or slice to obtain settings.

Included: one saved BBL-family FFF 3MF, a standalone settings file action with a supplied machine and process, and either two explicit filament slots or no supplied filament files. A CLI end-to-end test compares the complete JSON from a synthetic Native-exported two-slot cube for A;A, A;B, machine/process only, and unchanged no-load A;A, using each Native oracle. The A;A and A;B outputs must retain two slots and differ in their mapping behavior.

Deferred: non-BBL explicit exports and saved no-load composition changes; other partial, empty-slot and `--uptodate` combinations; wider printer-switch and multiple-variant behavior; combined slice/export actions; changes to tower cancellation or the 3MF writer.
