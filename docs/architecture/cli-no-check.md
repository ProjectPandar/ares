# Direct CLI `--no-check`: retained validation errors and support necessity

Upstream: OrcaSlicer v2.5.0 (`40ecc66f7`). This slice ports the report behavior for an existing fatal `Print::validate` result. It does not mean “disable validation.” The witness is a synthetic 3MF with two by-layer spiral-vase copies. Both orders of `--no-check` and `--slice` must still fail with `CLI_VALIDATE_ERROR` (`-51`, POSIX exit 205). Only when `--no-check` precedes `--slice` does `result.json.error_string` carry the validator's diagnostic instead of the generic CLI message. Stderr contains the same diagnostic in both modes; neither mode emits G-code. A successful synthetic STL slice is a control for the full report and complete exported G-code.

## Rust boundary

The direct CLI keeps the global `--strict` pair rejection and derives the slice-local flag from the argument indices. On the direct project route, the existing `ares-core::print::validate` produces `SliceError::Validate`. The CLI uses its diagnostic for the report when the slice-local flag is active. Do not change the validator, G-code writer, existing warning types, `slice` subcommand, or WASM API. Verify with identical argv for both binaries, isolated cwd and private Native temporary directories. Check exit, stdout/stderr, recursive output inventory including cwd, the complete report (normalize elapsed times only), and the complete G-code when present (normalize only the generator identity and generation timestamp).

For support necessity, carry the ordered direct CLI flag in the per-slice `SlicerContext` on the direct project and STL paths. Skip the existing `ares-core::project_slice::support_material::necessity::check` before geometry or progress reporting; leave support/raft generation, other warnings, validation and the existing CLI warning policy and writer untouched. The default context still checks, including the `slice` subcommand and WASM callers.

Use a synthetic cantilever STL with support off in its loaded preset. With no flag or a flag after `--slice`, the report must retain the support warning and its plate message; before `--slice`, neither is produced. All three orders must match Native on exit, stdout/stderr, cwd inventory and complete report. First compare all three complete Native G-code exports; if unchanged apart from the generator line, compare complete G-code with Ares using the same normalization.

Deferred: other validation error families, the unproduced layer-height downgrade, typed critical notification promotion, the processing-time path conflict checker, all-plates and repeated-action traversal, and any separate G-code/3MF checking coverage. The direct option does not claim any of these suppressions. Do not reuse it to skip the independent post-export bounds gate.
