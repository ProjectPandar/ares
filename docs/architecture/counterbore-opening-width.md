## Rust destination

- `crates/ares-core/src/project_slice/perimeters/classic/counterbore.rs` (`partial_mask`, line 222).

Both Classic (`prelude.rs:84`) and Arachne (`arachne/materialize.rs:150`, consuming `prelude_record.counterbore_fill`) share `counterbore::process` and `partial_mask`, matching the shared upstream `PerimeterGenerator::process_no_bridge` boundary.

The existing call at `counterbore.rs:222` is a temporary mismatch that passes `spacing as f32` (`perimeter_spacing`) instead of `(width / 2) as f32` (`ext_perimeter_width / 2`). Because `perimeter_spacing` is roughly `1.7x–1.8x` larger than `ext_perimeter_width / 2` for standard 0.4 mm nozzle flows, the noise-filter opening over-erodes `bridgeable_filtered` before restoration.

## Included and deferred behavior

### Included

- Update `partial_mask` in `crates/ares-core/src/project_slice/perimeters/classic/counterbore.rs` so the post-`difference_ex_with_safety_offset` `opening_ex` call passes `(width / 2) as f32` (matching integer truncation of `coord_t` `ext_perimeter_width / 2` converted to `float`) with `JoinType::Miter` and miter limit `3.0`.

### Deferred

- Conditional `last = remaining` update when `unsupported_filtered` becomes empty (`PerimeterGenerator.cpp:2299–2301`, where `counterbore.rs:160` currently updates `last` unconditionally before `partial_mask`).
- `chbFilled` (`PerimeterGenerator.cpp:2187–2265`), `BridgeDetector` coverage computation, and downstream perimeter or infill generation outside `PerimeterGenerator.cpp:2289`.

## Failure modes

- On rotated stepped counterbore slots whose post-subtraction bridge mask has mitered corners or narrow spans between `ext_perimeter_width / 2` and `perimeter_spacing`, using `perimeter_spacing` as the opening radius over-erodes or alters polygon corners before the `+perimeter_spacing` restoration offset, shifting wall and bridge infill geometry.
- Using floating-point division (`width as f32 / 2.0`) instead of integer division (`(width / 2) as f32`) would diverge by `0.5` scaled unit (`0.5 nm`) on odd `coord_t` widths (such as `419999`), breaking exact argument parity with `coord_t` `ext_perimeter_width / 2`.

## Verification

Slice synthetic stepped counterbore 3MF projects with elongated rectangular slots rotated by `15°`, `37°`, and `6.003°` (`tests/parity/counterbore-partiallybridge/rotated-slot-15.3mf`, `rotated-slot-37.3mf`, `rotated-slot-6p003.3mf`) with `counterbore_hole_bridging = "partiallybridge"` and `wall_generator = "classic"` through the public project-plate slicing API, and compare the complete G-code bytes (excluding only the single `; generated by` header line) against OrcaSlicer 2.5.0. Retain existing Classic and Arachne counterbore parity suites as controls.
