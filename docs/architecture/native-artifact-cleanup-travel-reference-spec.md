## 五个测试的不可放宽合同

| 原名（迁移后保持 active） | 必须保留的断言 |
| --- | --- |
| `avoid_crossing_perimeters_preserves_ordered_xy_travel_commands` | anchor 全部 `G1 X` 且不含 ` E` 的行，先相同行数，再逐条有序相等；重复舍入角点不删除 |
| `closest_line_extension_preserves_all_ordered_one_wall_xy_commands` | 同一过滤规则；Native 明确恰好 436 条；完整有序向量相等，保留重复角点 |
| `closest_line_extension_matches_complete_one_wall_orca_artifact` | 整份字符串相等，包括空白、M73、统计、CONFIG_BLOCK、所有 travel/extrusion 行；仅归一各自恰好一条严格匹配的 generator 行 |
| `extrude_loop_preserves_complete_ordered_sparse_runs_and_inward_move` | anchor Z `2.58/2.72/8.04` 整层逐字相等；每个 Native 层仍断言 `G1 X164.851 Y179.88\n` 和 `;TYPE:Sparse infill\n` 存在 |
| `two_wall_inward_move_preserves_orca_layer_sections` | two-walls Z `0.34/0.76/1.18` 整层逐字相等 |

完整 one-wall 归一函数保留现有 regex 和 `jiff::civil::DateTime` 校验：
Ares 行为 `; generated by Ares 2.4.2`，Native 行严格含版本、日期和时间，
匹配数各为 1；只替换该行，不 trim、不丢配置/footer/M73、不容差。
层区段仍从精确 `;Z:{z}\n` 开始，到随后 `;LAYER_CHANGE\n` 之前，
不缩减为 polygon、waypoint 或 footer 摘要。

## 运行时参照与依赖策略

一个本组私有 fixture adapter 复用既有 `ExportedCase` →
`OrcaRunner::slice_case` 缓存，把相同提交输入字节及原 basename 交给 Native。
不预热、不新增缓存框架，不把整个 runner include 到三个旧 binary。
五例共三个输入，anchor 与 one-wall 各被两个测试复用；锁和缓存发布沿用现有
producer 身份、输入/资源/replay 身份、staging、hash 校验和 receipt。

Ares 仍用 `Command` 调用公共 `slice -o <output> <fixture.3mf>`，优先使用
`ARES_TRAVEL_BIN`，未设置时用 `env!("CARGO_BIN_EXE_ares")`。保留退出状态
成功断言，不替换为 core 内部 API，不改变输入或覆写配置。

依赖检查只走片 A 的 `tests/support/native_environment` / `OrcaRunner::from_env`：
required (`ARES_REQUIRE_ORCA=1`) 缺 Native/工具即 FAIL，optional 可见 SKIPPED；
暖缓存不能绕过检查。执行、解析、字节不符都失败，不另写 skip 或 fallback。
本组不需要 gdb。Native/Ares 原始输出、producer/cache receipts、命令退出码与
SHA 仅保留在仓库外 artifact 目录，不提交任何 Native 产物。

## RED、GREEN 与退出证据

RED 单独提交：移除三份冻结参照，暂留旧读取入口，真实运行五个原测试，
记录它们因缺参照失败；这是参照生命周期的迁移 RED，不声称发现 routing
算法差异。GREEN 迁移五个测试并删除旧入口，运行时 Native 对比全部通过。
原测试体的比较规则逐项审计，输入 SHA 与迁移前一致。

required 冷/热各跑五例：冷轮验证三个唯一输入的真实 Native 生成与锁复用，
热轮验证相同 cache entry / 完整 reference SHA 且五例通过；同时验证
required/optional 缺依赖策略和暖缓存检查。保存两轮 receipts 与全输出。

在最新生产 main 上 fresh base/cand v2 seeded + official，记录完整状态变化、
共同 Ares raw SHA 与严格失败子集脚本原始结果。
新生产改动须刷新相应配对基线。任何 Native 波动保留原失败和双侧原始证据并逐例报告。

工程门禁：本组定向、`cargo nextest run --workspace`、
workspace/all-targets/all-features clippy `-D warnings`、fmt、
core/vgcode/wasm 的 wasm32 check。

Deferred：所有生产 travel 修复、额外 fixture/option 矩阵、Native 非确定性
修复、共享缓存/selector 策略调整及其它迁移组；无新增 ignore 或弱化断言。
