# Fuzzy skin: emit verbatim fuzzified scaled points (upstream parity)

Date: 2026-09-27. Boundary: `OrcaSlicer/src/libslic3r/Feature/FuzzySkin/FuzzySkin.cpp`
(`apply_fuzzy_skin` :561-578, `fuzzy_polyline` :294-340, `fuzzy_polyline_ripple` :159-219,
`ripple_anchor_arc_mm` / `ripple_anchor_point` :95-156) vs
`crates/ares-core/src/project_slice/perimeters/classic/materialize/path.rs` and
`crates/ares-core/src/perimeters/fuzzy_skin_noise.rs`.

## Problem

`fuzzy_skin_thickness/seeded` (case-3Mmtue) and every `fuzzy_skin_*` sweep case diffed
~2200 lines of 1–3 µm coordinate jitter on ripple-displaced outer/overhang wall
vertices (`X106.698` vs `X106.697`).

## Root causes fixed

1. **Lossy re-quantization after fuzzification.** `fuzzy_polygon` unscaled the
   fuzzified `Points` to mm, ran `simplify_linear_points` (Douglas–Peucker), and
   re-scaled via truncating `checked_scale`. Upstream keeps the coord_t points
   verbatim from `apply_fuzzy_skin` through extrusion — `x·1e-6 → /1e-6` truncates
   one unit low at float boundaries, and the displacement-sensitive values flip.
   Fix: return the fuzzified polygon untouched (upstream applies no extra
   simplify/rescale between `apply_fuzzy_skin` and extrusion).

2. **`seg_len*seg_len` vs `dx²+dy²`.** Upstream `closest_arc_mm` divides by
   `seg_len * seg_len` where `seg_len` is the already-computed square root
   (`FuzzySkin.cpp:135-150`); `sqrt(x)²` rounds differently than `x`. Fixed in
   `closest_arc_mm` and carried `seg_len_mm` through `accum_mm`.

3. **`perimeter_mm` accumulation order.** Upstream sums `unscale_(norm(scaled))`
   per segment — norm on scaled-i64 vectors, then unscale; summing mm-space
   distances rounds differently. Fixed in both `ripple_scaled_closed_polyline`
   and `ripple_closed_polyline`.

4. **Anchor flat-segment t.** `ripple_anchor_point` used `min(xa, xb)` for
   segments flat on Y=0; upstream uses `t = 0` → `x_cross = xa`. Fixed.

5. **`phase_at_anchor` grouping.** `sin` argument groups `X + (2π + phase_shift)`
   (`FuzzySkin.cpp:206-211`), not `(X + 2π) + phase_shift`.

6. **`hypot` → `sqrt(x²+y²)`** matching Eigen `.norm()` in the ripple path.

## Verification

`target/release/ares slice` on all 22 `fuzzy_skin*` sweep cases
now diffs exactly 2 lines (`; generated by` header
only). A standalone upstream-faithful C++ probe of `fuzzy_polyline_ripple`
(`fuzzprobe`) confirms our emitted scaled points are bitwise identical to the
upstream algorithm on every fuzzified layer of the case.
