# Consume `file_start_gcode` Design

## Goal

Port OrcaSlicer's top-of-file custom G-code slice into Ares so the existing `file_start_gcode` option affects generated G-code output. This is concrete option consumption, not new option metadata.

## Upstream Boundary

- `OrcaSlicer/src/libslic3r/PrintConfig.hpp:1385` defines `file_start_gcode` in `GCodeConfig`.
- `OrcaSlicer/src/libslic3r/PrintConfig.cpp:5777-5787` defines `file_start_gcode` as a multiline string option with default `""`, written at the very top of the output file, before any other content, and documents `{print_time_sec}` / `{used_filament_length}` placeholders.
- `OrcaSlicer/src/libslic3r/GCode.cpp:2519-2526` reads `print.config().file_start_gcode.value`, processes it through the placeholder parser with `print_time_sec` and `used_filament_length` mapped to `GCodeProcessor::reserved_tag(...)`, and writes the result before the header.
- `OrcaSlicer/src/libslic3r/GCode/GCodeProcessor.cpp:58-79` defines the BBL reserved tags `@PRINT_TIME_SEC@` and `@USED_FILAMENT_LENGTH@`.
- `OrcaSlicer/src/libslic3r/GCode/GCodeProcessor.cpp:81-102` defines the compatible reserved tags with the same two strings.
- `OrcaSlicer/src/libslic3r/GCode/GCodeProcessor.cpp:1112-1128` later replaces those reserved tags during post-processing.
- `OrcaSlicer/src/libslic3r/PrintConfig.cpp:11112` lists `file_start_gcode` in the custom G-code placeholder map without extra specific placeholders beyond the explicitly injected reserved-tag values.

## Ares Boundary

- Add a runtime accessor for the already registered `file_start_gcode` option in `crates/ares-core/src/options/custom_gcode.rs`.
- Extend `crates/ares-core/src/gcode_placeholders.rs` with a focused renderer for `file_start_gcode`.
- Wire rendered `file_start_gcode` into `crates/ares-core/src/gcode.rs` before `gcode_header::format_header(...)`.
- Add focused tests under the existing custom G-code/auxiliary fan test area rather than adding more registry metadata.

## Behavior

- If `file_start_gcode` is absent or `""`, generated G-code remains unchanged except for normal option-count comments when the empty option is explicitly provided.
- `file_start_gcode` accepts only JSON strings. A non-string value returns `SliceError::InvalidInput` and mentions `file_start_gcode`.
- A non-empty template is emitted as the first bytes of generated G-code, before `; generated by Ares`.
- A trailing newline is added when the rendered template does not already end with `\n`, so the existing header starts on its own line.
- The renderer replaces `{print_time_sec}` with `@PRINT_TIME_SEC@`.
- The renderer replaces `{used_filament_length}` with `@USED_FILAMENT_LENGTH@`.
- Unknown brace placeholders are preserved unchanged.
- Existing bracket placeholder replacement for `machine_start_gcode` is unchanged.

## Explicit Deferrals

- Do not add new option registry entries or metadata.
- Do not implement a general Orca placeholder parser.
- Do not compute final print time or filament length in this slice; Orca writes reserved tags first and replaces them later in `GCodeProcessor`, while Ares does not yet have that post-processing stage.
- Do not change `machine_start_gcode` placement or auxiliary fan placeholder behavior.
- Do not add filesystem, terminal, UI, OpenGL, or WASM-hostile behavior to `ares-core`.

## Acceptance Criteria

- A unit test proves `SliceOptions::file_start_gcode()` accepts strings, defaults absent values to `""`, and rejects non-strings with an error mentioning `file_start_gcode`.
- A G-code integration test proves non-empty `file_start_gcode` appears before `; generated by Ares`.
- A G-code integration test proves `{print_time_sec}` and `{used_filament_length}` become `@PRINT_TIME_SEC@` and `@USED_FILAMENT_LENGTH@`.
- A G-code integration test proves unknown placeholders remain unchanged.
- A G-code integration test proves absent and empty `file_start_gcode` produce equivalent output after removing only the option-count comment.
- Existing auxiliary fan and `machine_start_gcode` tests still pass.
- `cargo fmt --check`, `cargo test -p ares-core --lib`, `cargo clippy --workspace --all-targets -- -D warnings`, `git diff --check`, and the 400 LOC gate pass.
