# Consume `min_length_factor` Design

## Goal

Consume the existing OrcaSlicer `min_length_factor` option into concrete Ares perimeter behavior instead of leaving it as option metadata only. The slice is a source-cited Rust rewrite of Orca's short open wall-line removal boundary and must not add new option-only milestones.

## Upstream Source Boundary

- `OrcaSlicer/src/libslic3r/PrintConfig.hpp:1039` declares `((ConfigOptionFloat, min_length_factor))` in `PrintObjectConfig`.
- `OrcaSlicer/src/libslic3r/PrintConfig.cpp:7062-7074` defines the option label, tooltip, range `0.0..=25.0`, and default `0.5`.
- `OrcaSlicer/src/libslic3r/Arachne/WallToolPaths.cpp:34-37` copies `print_object_config.min_length_factor` into `WallToolPathsParams`, defaulting to `0.5`.
- `OrcaSlicer/src/libslic3r/Arachne/WallToolPaths.cpp:684-699` removes open odd wall lines whose polyline length is shorter than `min_width * min_length_factor`, while top or bottom layers use `min_width / 2` instead to avoid visual gaps.

## Rust Destination Boundary

- Parse `min_length_factor` in `ares-core` perimeter options as an internal `PerimeterOptions` scalar with default `0.5` and accepted range `0.0..=25.0`.
- Apply the option only to Ares' existing open rectangular thin-wall centerline generated by `crates/ares-core/src/perimeters/thin_walls.rs`.
- Treat that generated open centerline as the Ares equivalent of Orca's short open wall line for this slice: remove it when its length is below `external_line_width * min_length_factor` on non-top/bottom layers.
- Treat layer `0` and the topmost generated layer as the Ares top/bottom-protected cases for this slice: those layers use `external_line_width / 2` instead of the configured factor, matching the Orca branch that avoids top/bottom visual gaps.

## Included Behavior

1. `SliceOptions::perimeter_options()` accepts numeric or string numeric `min_length_factor`.
2. Missing `min_length_factor` defaults to `0.5`.
3. Values outside `0.0..=25.0`, non-finite values, and non-numeric JSON values return `SliceError::InvalidInput` mentioning `min_length_factor`.
4. With `detect_thin_wall = true`, a non-top/bottom thin-wall centerline shorter than `external_line_width * min_length_factor` is omitted from perimeters, print paths, region perimeter extrusion, and G-code.
5. The same centerline remains when it is at least that threshold.
6. First and topmost layers do not use the configured factor; they keep centerlines at or above `external_line_width / 2`, preserving Orca's top/bottom protection branch.

## Deferred Behavior

- Full Arachne `VariableWidthLines`, `ExtrusionLine::is_odd`, junction width scanning, and non-rectangular open wall generation remain deferred.
- Full top/bottom surface classification beyond Ares' current first/topmost layer knowledge remains deferred.
- `min_feature_size`, `min_bead_width`, `initial_layer_min_bead_width`, wall transition filtering, wall maximum resolution/deviation, and complete Orca Arachne parity remain deferred.
- Orca binary E2E geometry parity remains deferred; this slice uses source-cited unit/pipeline/G-code tests over the current Ares thin-wall surface.
