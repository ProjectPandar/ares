# Spec: Task 22O.124 monotonic configured direction

## Observable contract

`ProcessInfillPattern::Monotonic` uses `solid_infill_direction` unchanged on every non-bridge layer. Consecutive layer indices must not rotate the pattern by 90 degrees. A bridge surface still uses its resolved bridge angle.

For `ksr_fdmtest_v4.project.3mf`, this removes the alternating dense cross-band zigzags generated by Ares and retains option-derived monotonic paths. Production code must not inspect fixture identity or expected G-code.
