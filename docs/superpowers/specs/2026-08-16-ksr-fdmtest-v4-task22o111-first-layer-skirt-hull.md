# Spec: Task 22o.111 first-layer skirt hull

## Observable contract

The project G-code emitter resolves `first_layer_print_min`, `first_layer_print_max`, and `first_layer_print_size` from the same first-layer convex hull used by OrcaSlicer. For the KSR project, `skirt_height = 1` and `skirt_distance = 2` expand the compensated first-layer island footprint by 2 mm on every side even when `skirt_loops = 0`.

## Upstream boundary

Port `OrcaSlicer/src/libslic3r/Print.cpp:575-586`, `2646-2775`, and `3154-3163`: finite/infinite skirt presence, occupied-layer hull collection, the zero-loop skirt hull offset, and first-layer-convex-hull finalization. The Rust destination is `crates/ares-core/src/project_slice/gcode_emit/footprint.rs`; it consumes typed effective project options and retained compensated layer slices.

## Included behavior

- Select occupied layers according to typed `skirt_height` semantics.
- Select all occupied layers for an enabled infinite draft shield.
- Expand the occupied hull bounds by typed `skirt_distance`.
- Fall back to compensated first-layer bounds when no skirt hull is generated.

Brim, support, and wipe-tower hull contributions are deferred because those upstream geometries are not generated by the current project-slice boundary.
